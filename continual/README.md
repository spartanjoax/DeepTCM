# continual/

Continual learning extensions built on [Avalanche v0.6.0](https://github.com/spartanjoax/avalanche_multimodal) (forked to add multimodal dict input `{x, proc_data}` and regression support). Implements six use cases for cross-machine, cross-material, and cross-condition tool wear adaptation.

## Files

| File | Description |
|---|---|
| `strategies/` | Custom Avalanche strategy wrappers (see `strategies/README.md`). |
| `metrics/` | Regression evaluation plugins for Avalanche (see `metrics/README.md`). |
